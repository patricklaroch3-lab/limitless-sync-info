Github_Limitless

Github_Limitless is a small personal automation tool. Once a day it copies the owner's own Limitless lifelogs into plain text files in a folder in the owner's own Google Drive.

What it does

  • Reads the owner's lifelogs from the Limitless API using the owner's own API key.
  • Creates and updates one text file per day in a single Google Drive folder belonging to the owner.
  • Runs on a schedule using GitHub Actions.

Who uses it

This tool is used only by its developer, Patrick Laroche, with his own accounts. It is not offered to the public and has no other users.
