Privacy Policy

Github_Limitless · Last updated: November 13, 2026

Github_Limitless is a personal automation tool built and used by one person, Patrick Laroche, to copy his own Limitless lifelogs into his own Google Drive. It is not a public service.

Google user data

The tool asks for one Google permission, https://www.googleapis.com/auth/drive.file. This lets it create and update only the files it created itself in a Drive folder belonging to the account owner. It cannot see, read, or change any other file in the Google Drive account.

What is collected and stored

The tool collects nothing about visitors or other users. The only data it handles is the owner's own Limitless lifelog text, which is written to text files in the owner's own Google Drive. A Google refresh token is stored as an encrypted secret in the owner's private GitHub repository so the scheduled job can sign in.

Sharing

No data is sold, shared with, or disclosed to any third party. There are no advertising, analytics, or tracking tools. Data goes only from the Limitless service to the owner's Google Drive.

Retention and deletion

The files remain in the owner's Google Drive until the owner deletes them. Access can be revoked at any time at myaccount.google.com/permissions.

Google API Services User Data Policy

This tool's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
